Comportement du menu

  • Éléments plats au premier niveau, avec l'icône mSOUND ; formats affichés réglables dans les réglages (par défaut les 7 courants).
  • Plusieurs fichiers sélectionnés : conversion par lot, avec une petite pastille de progression ; le fichier converti se place à côté de l'original, sans fenêtre.
  • Conversion sans perte quand elle est possible (WAV ↔ AIFF ↔ FLAC ↔ ALAC) ; si le format cible est le même, copie sans ré-encodage.
  • « Éditer avec mSOUND » ouvre l'éditeur ci-dessus sur le fichier.
